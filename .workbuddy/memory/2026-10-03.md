## v2.74（第七十轮）正方识别面板被裁到无法操作（阻断）+ 历史入口贴紧 Uni 标题

### 背景

产品负责人带两张真机截图提两件事：

1. 「**图一你UI都显示不全我怎么添加**」—— 正方识别面板上下都被切，**阻断性 bug**，根本没法操作。
2. 「**图二把历史对话固定在最顶部的UNI下面**」。追问后选定 **「位置贴紧 Uni 标题」**。

### A. 正方识别面板：`.mask` 撑破视口

v2.71 建面板时遮罩是 `.mask { position: fixed; inset: 0; overflow: auto; padding: 14px … }` —— **只滚动、不限高**。
面板内容（智能识别卡 + 5 字段 + 提示 + 预览 + 3 按钮）远超视口，`.mask` 是 `overflow:auto` 且面板没有 `max-height`，
结果上边顶出屏幕（标题/抓手条看不见）、下边"添加并导入"也滑到屏外。

修法：**遮罩只负责居中 + 把面板限高，面板内部自己三段式。**

- `.mask` → `display:flex; align-items:center; justify-content:center; overflow:hidden`
- `.idpanel` → `max-height: calc(100vh - 28px - var(--safe-b))` + **再写一行 `dvh` 覆盖**（`vh` 回退老 WebView）+ `display:flex; flex-direction:column`
- `.idhead` → `flex:none`（原 default `0 1 auto` 会被压缩）
- `.idbody` → **新增** `flex:1; min-height:0; overflow-y:auto; -webkit-overflow-scrolling:touch; padding:0 2px`（全屏唯一滚动区）
- `.idfoot` → **新增** `flex:none; padding-top:4px; border-top:1px solid var(--line); margin-top:12px`
- 模板插入 `<div class="idbody">…</div><!-- /.idbody -->` 与 `<div class="idfoot">…</div>` 包住两组按钮

### B. Uni 历史入口：从"吸顶"到"贴紧 header"

`.head` 是 `Main.vue` 的全局 sticky 标题栏（`top:0; z-index:30`），**是 `.uni-chat-page` 的兄弟、不在滚动流里**，
所以 `top:0` 本来就贴在它下面 —— **位置本来就对，问题在"还有一条缝"**（v2.73 只写了 `margin: -12px -12px`）。

- `width: 100%` → `auto`（配合出血做通栏；`100%` 是内容盒宽度，出血会被压回）
- `margin: -12px -12px 10px` → `-12px -16px 10px`（横向也出血到 `.scroll` padding 边界，底色条**通栏**）
- `padding: 12px 12px 10px` → `10px 16px`（与上面对称）

### 测试

- `tests/school.test.ts` **105 → 108**（+3）：遮罩 flex 居中且不再自己滚、面板限高（dvh 优先 + vh 回退两条都在）、三段式齐全（含模板里两个 class 真出现）
- `tests/agent.test.ts` **81 → 82**（+1）：历史入口贴紧标题栏（`margin: -12px -16px 10px` **且** `width: auto`）

### 验证

- 全量 **31 套件 / 1364 条断言**全绿（`agent` 82 / `school` 108 / `css` 42 / `p5-prototype` 3 …）

  `.idpanel[data-v-6ef0f457]{…max-height:calc(100vh - 28px - var(--safe-b));max-height:calc(100dvh - 28px - var(--safe-b));display:flex;flex-direction:column;…}`、

### 本轮踩的坑

1. **遮罩 `overflow:auto` + 面板不限高 = 小屏上"面板被裁、按钮点不到"**（阻断性）。
   **规矩：全屏遮罩只做"居中 + 限高"，面板内部拆三段（头固定 / 身唯一滚动 / 脚固定）。**
   `flex:1` 必须配 `min-height:0`，否则子项撑不缩、滚动条不出现。
2. **高度用 `vh` 而不是 `dvh`**：软键盘/地址栏改变可视高度时 `vh` 不跟着缩 → 按钮又跑到键盘底下。移动端优先 `dvh`，`vh` 只作回退（同属性写两行）。
3. **"负边距抵 padding"只抵了一半**：只写 `-12px -12px` 时横向仍是原宽度、底色条不通栏。**做贴边/通栏要四个方向一起对，且把 `width:100%` 改成 `auto`。**
4. **布局断言要断"组合条件 + 具体数值"**：V2.73 的"只验 sticky 关键词"教训重演 —— 断言写成三条同时成立 + 精确到 `margin: -12px -16px 10px`。

| 位置 | 原写法 | 后果 | 现修法 |
