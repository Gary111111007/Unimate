# Unimate

**中文** | [English](./README_EN.md)

> 高校校园学习生活一站式智能助手。把课表、记事、第二课堂和校园服务放在一起，让 Uni 帮你处理日常学习生活中的小事。

Unimate 以 **北京化工大学**为首个落地高校，面向 Android 开发，应用包名为 `com.unimate.app`。项目当前定位为学生自制演示作品及个人自用；具体功能和验收口径以 [PRD](./PRD.md) 及 [项目上下文](./docs/context.md) 为准。

## 功能介绍

### 课表：查看、管理与分享

- 按周查看课程、上课时间和地点，切换周次并查看下一节课；课程可用颜色区分，也可以手动调整。
- 手动添加和编辑课程，维护学期起始日期、总周数及节次时间；可新建和切换多份课表。
- 从教务系统导入课表。北化在应用内打开教务页面，由学生自行登录、查询并触发识别；其他学校的正方系统使用另一条导入链路。识别结果受学校系统与页面变化影响。
- 分享课表，生成分享内容及二维码。分享前请自行检查内容，避免不必要地公开个人课表。
- 课表和相关待办可设置本地提醒。Android 后台提醒受通知、闹钟权限与厂商省电策略影响，准时性需要在设备上实际验证。

### 记事与考试

- 记录待办事项，填写标题、内容、提醒时间等信息，并支持编辑、完成、搜索和筛选。
- 在适配的教务页面中识别考试安排，写入记事本并设置提前 1 天和 30 分钟的提醒；重复识别会跳过已存在的安排。
- 成绩查询支持在教务页面识别成绩并保存到本机。**成绩不上传账号云端，也不随换机备份携带**；识别和覆盖已有成绩时需要用户确认。
- 教务页面由用户自行登录与操作，应用不代填教务账号密码。具体入口和识别能力取决于学校档案与教务页面。

### 第二课堂与材料

- 北化档案提供德、智、体、美、劳五个板块，可记录活动、时间、说明、自评分数与照片，并查看分类和汇总统计。
- 拍照水印可自主开关；支持本机生成水印及照片存证信息，地址可手填，不依赖第三方地图 Key。可导出单条记录及相关材料。
- 分数是**自评参考**，并非学校官方认定结果；实际认定以学校规定为准。北二外档案不含第二课堂。

### 校园在线与工具

- 从学校档案进入教务、课程、图书馆等校园网站；网页登录和使用受学校网站及网络状态影响。
- 北化校园工具包括离线建筑示意图、MOTION 公开场馆状态、本机体测分数估算、教务空闲教室查询及课程目录/选课目标管理。
- 校园地图是示意图而非测绘导航；体测结果是估算。部分查询需要网络或先登录学校系统。选课工具可查看和保存目标、打开学校选课页面，**不代替用户提交选课**。
- 天气为默认关闭的可选功能；开启后联网获取信息。

### Uni 文字助手

- 可用文字询问今天或明天的课、查询本机记事、打开页面，或提出新增记事和提醒的请求。新增记事和提醒需用户确认后执行。
- 常见请求优先由本机规则处理；开放式问题可经 Unimate 在线服务处理。网络或服务不可用时会尝试本机规则，不能保证所有问题都能离线回答。
- 在线请求包含用户主动发送的文字；客户端不会自动附带课表、教师、教室或记事内容。请勿在对话中主动发送不希望共享的信息。详见 [Uni 架构](./docs/agent-architecture.md)。

## 高校与教务支持

| 高校 | 档案与能力 |
| --- | --- |
| 北京化工大学（北化） | 首个落地高校，档案随 APK 内置并置顶；课表使用北化页面表格解析链路。 |
| 北京第二外国语学院（北二外） | 通过签名云端档案提供：下载前显示“可下载”，下载后才可使用；不含第二课堂。 |
| 其他高校 | 在选校列表中标记“开发中”，不能视为已支持。可通过课表识别入口尝试正方教务导入，结果取决于实际系统；强智、URP 等类型尚未完成导入链路。 |

学校档案和声明式解析规则包支持签名校验与更新；校验失败时回退到内置内容。相关设计见 [学校档案](./docs/school-pack.md) 和 [解析适配器](./docs/adapters.md)。

## 数据、备份与隐私

本机保留完整的一份应用数据，云端用于备份和取回。**两种云模式的信任边界不同：**

| 方式 | 工作方式与取舍 |
| --- | --- |
| 账号登录（默认主推） | 课表、记事、第二课堂材料与照片可备份到云端，换机后登录可取回；密码原文不上传，客户端派生验证值。服务端持有落盘密钥，因此可以读取备份内容。 |
| 端到端加密同步（可选） | 使用同步码或账号与口令派生同步码；服务端只存 AES-256-GCM 密文，同步口令和恢复码不上传、不落盘。忘记口令且丢失恢复码时无法找回。 |
| 本机 ZIP 备份 | 可导出和导入 `.unimate.zip`，也可在登录页“账号与找回”中进行离线换机。成绩不包含在换机备份中。 |

云端当前使用 **Cloudflare 境外节点**，账号模式的可读备份涉及数据出境。面向真实用户运营前，应迁移至境内存储，或按个人信息保护和数据出境规定处理。服务部署与密钥说明见 [云服务文档](./cloudflare/sync-worker/README.md)。

## 快速体验

1. 启动项目后，登录页选择 **“用演示账号登录”**（`admin` / `buct`）。
2. 选择学校并浏览示例课表、记事和第二课堂；演示数据经过脱敏处理。
3. 尝试课表工具箱、记事本和 Uni。桌面浏览器中部分原生入口使用演示样本或降级，不能替代 Android 体验。

账号登录态会持久化；首次登录、退出后重新登录以及换学校等场景需要相应的联网条件。实际服务可用性取决于部署与网络。

## 开发、测试与构建

### 环境与本地运行

项目使用 **Vue 3、TypeScript、Vite、Pinia、Capacitor 6**，云端服务使用 Cloudflare Workers、Pages 和 R2。需要 npm 与支持 `--experimental-strip-types` 测试脚本的 Node.js 版本。

```bash
npm ci
npm run dev
```

按终端给出的地址打开浏览器。依赖安装和构建会产生文件；在 Windows 环境操作前请完整阅读 [C 盘存储策略](./C_DRIVE_STORAGE_POLICY.md)，并按要求配置下载、缓存及产物位置。

### 常用测试

```bash
npm run test:parser    # 北化课表解析
npm run test:academic  # 成绩与考试识别
npm run test:sync      # 云同步
npm run test:boot      # 启动流程
npm run test:order     # 声明顺序和重名检查
npm run test:css       # CSS 约束检查
npm run test:agent     # Uni Agent
```

完整测试命令见 [package.json](./package.json)。修改源码或界面时，按 [工程约定](./AGENTS.md) 执行相应检查；上面的命令清单不表示本次运行结果。

### Android 出包

准备 JDK 17、Android SDK 34 和项目所需的 Node.js 环境；首次搭建可参考 `scripts/setup-android-toolchain.ps1`，先检查下载及存储位置。正式出包使用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build-apk.ps1
```

脚本运行测试、构建、同步 Android 并反查包内容；产物为 `artifacts/android/unimate-debug.apk`。WebView、相机、文件选择、通知及后台提醒等原生行为仍需真机检查。不要仅凭构建成功声称真机通过。

## 项目结构与技术架构

```text
src/                  Vue 页面、组件、Pinia 状态与业务服务
android/              Capacitor Android 工程与原生桥
cloudflare/           账号、备份、Pages 中转与在线助手服务
catalog/             学校档案源文件
public/catalog/      签名清单与可下载档案
adapters/             声明式解析规则包
fixtures/             脱敏样本
tests/                自动化测试
scripts/              构建、发布和检查脚本
docs/                 架构、部署及项目上下文
p4-parser/            成绩/考试解析独立工位
p5-assistant/         AI 助手独立工位
```

应用界面与本机数据层位于 `src/`；Android 原生桥提供 WebView、通知等设备能力；云端提供账号备份、加密同步和在线助手接口。P4/P5 是独立工位，不直接作为主工程修改范围；具体整合情况请查看各自的 README 和 NOTES。

## 限制与相关文档

- 其他高校的“开发中”状态不等于已适配；教务页面变化、认证方式及网络条件都可能使导入失败。
- 浏览器预览和自动化测试不能替代真机检查；提醒还受设备权限和后台策略影响。
- 本项目包含学校相关入口和自评工具，不代表学校官方应用或官方评分结果。
