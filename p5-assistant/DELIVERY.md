### 5.2 坑一：CRLF 会让测试误报（已修）

`run-security-tests.mjs` 的 `stripComments` 原实现：

```js
src.split('\n').map((l) => l.replace(/\/\/.*$/, '')).join('\n')
```

**在 CRLF 文件上完全不工作**：JS 里 `\r` 是**行终止符**，`.` 不匹配它 →
`.*` 停在 `\r` 之前、`$`（无 `m`）只匹配输入末尾 → **整条注释没被剥掉** →
`roundtrip-check.mjs` 里那句「本文件里没有任何 rmSync」的说明被当成真的 `rmSync` → **J 组误报红灯**。

**修法**：先 `replace(/\r\n?/g, '\n')` 归一化行尾，再剥注释。

> **通用规矩**：任何「读源码文本再判断」的断言，都要先问一句：**它在 CRLF 下还成立吗？**
> 红灯的原因如果是注释或行尾，那说明**判据写错了**，不是代码错了。

### 5.3 坑二：空目录不进 Git

`credentials/` 原本是空目录 → Git 完全忽略它 → 新克隆出来没有这个目录 → K 组断言失败。
**修法**：放 `.gitkeep` 占位，并把判据从「目录里什么都没有」改成
「**排除占位文件后，凭据文件数为 0**」。口径差异见 §二.3。

### 5.4 坑三：版本号写死必然漂移

`docs/open-questions.md` 的 OQ-01 一度写死「真源为 v2.3.7」，而主规划已经升到 v2.3.9。
**修法**：改成「真源为 `chatgpt produce` 目录下同名文件，**当前版本见该文件首部**」。
历史版本号保留但标为「**历史快照**」。

## 九 一句话交接

**可以直接拿去答辩**：**「规则优先、核心能力离线可用、模型链路关闭、Agent 云端请求采用最小数据投影」**——

> ⚠️ **不要说「数据不出网」**：Agent 请求**确实会出网**（`message` + 最小 `contextCapsule`，出得少且白名单化）；

这几样一项都没做。
